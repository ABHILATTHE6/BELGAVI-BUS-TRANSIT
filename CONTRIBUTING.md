# Contributing to Belagavi City Bus Transit

Thank you for contributing to this project.

## Development Workflow

1. Fork the repository or create a feature branch.
2. Install dependencies with `npm install`.
3. Create a local `.env` file from `.env.example`.
4. Run the development server with `npm run dev`.
5. Run the TypeScript validation with `npm run lint`.
6. Build the application with `npm run build`.
7. Keep commits focused and use clear Conventional Commit messages.

## Commit Convention

Use prefixes such as:

- `feat:` for a new feature
- `fix:` for a bug fix
- `docs:` for documentation
- `refactor:` for code restructuring
- `test:` for tests
- `ci:` for CI/CD changes
- `chore:` for maintenance

## Pull Requests

- Explain what changed and why.
- Include screenshots for meaningful UI changes.
- Confirm that linting and builds pass before requesting review.
- Do not commit secrets, API keys, passwords, or local environment files.
